Against the 0.685 baseline, our final model gains $+0.014\pm0.004$, almost all from the
hidden-knockout correction ($+0.012\pm0.003$); the history adds only $+0.002\pm0.004$. On the private leaderboard
(Table~\ref{tab:results}) the two best tie at 0.683, 1.5 points below validation. The forecast pipeline tuned its blend on the same out-of-fold predictions, so its validation
is optimistic. We prefer the
hidden-knockout model because its gain is explained. Code at
\url{https://github.com/teoang/fds-pokemon-challenge}.
